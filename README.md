## Project Overview
This project demonstrates how structured prompt design (adjusting instructions, tone, length, complexity, and temperature) guides Large Language Models (LLMs) to perform tasks accurately across four distinct functional domains[cite: 1, 2].

## Functional Domains & Prompt Catalog (12 Blueprints)
1. **Answering Questions:** Concise & Bulleted, Academic Breakdown, ELI5 Metaphors[cite: 1, 2].
2. **Text Summarization:** Executive Summary, Section TL;DR, Critical Review[cite: 1, 2].
3. **Creative Content:** Rich Narrative, Rhythmic Poetry, Sci-Fi Pitch[cite: 1, 2].
4. **Advisory & Guidance:** Phased Roadmap, Socratic Coaching, Strategic SWOT[cite: 1, 2].

## Key Features
* **Assistant Studio:** React 18 + Vite web frontend featuring a dark glassmorphism design[cite: 1, 2].
* **Console CLI:** Python 3.12 interactive command-line assistant (`assistant_cli.py`)[cite: 1, 2].
* **Prompt Comparison Matrix:** Runs three prompt variations simultaneously for side-by-side comparison[cite: 1, 2].
* **Closed-Loop Feedback:** Response rating modal (1–5 stars, Yes/No helpfulness verdict, quality tags, and text suggestions) with an analytics store[cite: 1, 2].
* **API & Offline Backends:** Live OpenAI / Google Gemini API integration alongside a Smart Offline Engine fallback[cite: 1, 2].
